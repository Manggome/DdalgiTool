# 딸각기획 (딸기툴 🍓)

> **대화 한 줄로 게임 기획 잡무를 끝내는 도구.**
> 기획서·데이터 시트·슬랙·트렐로·유니티 프로젝트를 하나로 연결해,
> 흩어진 자료를 일일이 찾아다니지 않고 **말로 물어보고 시키면** 됩니다.

딸기툴은 채팅 앱처럼 생겼습니다. 가운데 입력창에 평소 말하듯 적으면 됩니다.

> "이번 기획서 요약해줘"
> "데이터 테이블이랑 기획서 안 맞는 데 점검해줘"
> "출석 보상 기능 유니티에서 테스트해줘"

뒤에서는 Claude(개인 계정으로 로그인)가 연결된 문서·시트·슬랙·트렐로·유니티 프로젝트를 직접 읽고 일합니다.

---

## 이런 게 번거로우셨다면

- 기획서가 문서 여기저기, 시트 여기저기 흩어져 있어 **매번 찾아 헤맨다**
- 기획서·데이터·코드가 **어디서 서로 어긋났는지** 눈으로 못 잡는다
- 슬랙에서 정해진 결정이 **스크롤 위로 사라져** 다시 못 찾는다
- 기획서에 달린 **댓글·수정 요청**을 하나하나 열어보기 귀찮다
- QA 항목을 **매번 처음부터** 손으로 정리하고, 직접 플레이하며 확인한다

딸기툴은 이걸 "말하면 해주는" 방식으로 바꿔줍니다.

---

## 무엇을 할 수 있나요

자주 하는 기획 업무를 아래 9가지로 익혀뒀습니다.
**이름을 외울 필요는 없어요** — 그냥 말하면 딸기툴이 맞는 일을 알아서 고릅니다.

| | 할 수 있는 일 | 이렇게 말해 보세요 |
|---|---|---|
| **쓰기** | 📝 **기획서 쓰기·고치기** — 읽고 답하기, 고치기, 예외처리 검수, 양식 그대로 새로 쓰기, 댓글 반영 | "패키지 기획서 요약해줘", "양식대로 낚시 기획서 써줘" |
| | 📊 **데이터 테이블 만들기·고치기** — 값 찾기, 고치기, 오류 검수, 기획서 보고 새 테이블 | "상점 테이블에서 가격 0인 거 찾아줘" |
| **확인** | 🔍 **찾기 · 바꾸면 영향 찾기** — 슬랙·트렐로·문서·코드·깃을 가로질러 찾기 | "출석 2배 어디서 정했지?", "골드 획득량 바꾸면 어디가 영향받아?" |
| | 🧭 **어긋난 곳 점검** — 기획서·테이블·코드·트렐로를 대조해 심각도 순 보고서 (지난 점검과 비교) | "프로젝트 전체 점검해줘" |
| | ⚖️ **밸런스 계산·시뮬레이션** — 실제 코드 수식과 데이터로 계산, 바꿔 보는 시뮬레이터 | "30일 출석 시 총 골드 계산해줘" |
| **테스트** | ✅ **QA 하기** — 대상 정하기 → 테스트 케이스 → (원하면) 🎮 유니티에서 직접 플레이하며 테스트 → 결과 보고서 | "이번 주 개발 끝난 카드 QA해줘" |
| **정리** | 🩺 **게임 진단 보고서** — 기획 문제점(근거 인용) + 최신 트렌드 기반 개선점 | "우리 게임 문제점이랑 개선점 진단해줘" |
| | 🗂 **결정 기록하기** — 결정 기록, 슬랙 대화 백업, 예전 결정 이유 찾기 | "방금 정한 거 기록해둬" |
| | 🗺 **설계 지도** — 시스템·재화·테이블·기획서·코드가 어떻게 이어지는지 지도로 | "설계 지도 만들어줘" |

그 밖에 문서의 **여러 탭**도 전부 읽고, 문서에 달린 **댓글·답글**도 모아서 정리합니다.

## 이렇게 써요

- **시작 버튼** — 새 대화를 열면 "무엇을 할까요?" 아래에 위 9가지가 버튼으로 나옵니다. 눌러서 시작해도 되고, 그냥 말해도 됩니다.
- **고르기 버튼** — 딸기툴이 "어떤 기획서요?"처럼 물을 때는 후보가 **버튼으로** 나옵니다. 파일명이나 ID를 외울 필요가 없어요.
- **🗺 설계 지도** — 사이드바 버튼을 누르면 오른쪽에 지도가 열립니다. 점을 누르면 원본으로 이동하고, [이거 바꾸면 영향]으로 영향받는 곳을 강조합니다.
- **결과물** — 보고서·체크리스트·시뮬레이터는 HTML 파일로 작업 폴더에 저장되고 오른쪽 패널에 바로 열립니다.
- **입력창 아래 설정**
  - **모델** — 기본은 Sonnet 5.5(빠름). 어려운 일은 Opus 5.5, 가장 어려운 일은 Fable 5.1
  - **노력** — '기본'이면 일에 맞춰 알아서 정합니다 (찾기는 빠르게, 점검·QA는 꼼꼼하게)
  - **비용 상한** — 한 대화에서 쓴 금액이 넘으면 작업을 멈춥니다. 다시 요청하면 이어서 진행
- **옆에서 도는 작업도 보여요** — 딸기툴이 일을 나눠 맡기면(서브 에이전트) 각각 카드로 지금 무엇을 하는지 보여줍니다.

| 연결 | 하는 일 |
|---|---|

## 안전장치

기획 자료를 다루는 도구라, 실수로 뭔가 망가지지 않도록 선을 그어놨습니다.

- **바깥에 쓰는 일은 항상 먼저 확인** — 구글·슬랙·트렐로에 기록하기 전에 "이렇게 바꿀게요" 카드가 뜨고, **허용을 눌러야** 실행됩니다
- **삭제 기능 없음** — 지우지 않습니다. 꼭 필요하면 이름 앞에 `[삭제용]`이라고만 표시합니다
- **슬랙은 등록된 채널만** 읽습니다
- **유니티 프로젝트는 바꾸지 않음** — 코드·씬·에셋은 읽기만 합니다. QA 플레이 테스트도 플레이·스크린샷·콘솔 확인만 하고, 수정·저장은 앱이 막습니다. 플레이 전에는 꼭 물어봅니다
- **로그인 정보는 맥·윈도우 키체인에** 암호화 저장 (채팅창에 붙여넣지 않음)
- **내 컴퓨터 파일은 되돌릴 수 있음** — 파일을 만들거나 고친 답변 끝의 [↩ 이 요청 전으로 되돌리기]
- **다른 앱을 보고 있어도** 승인 요청·선택 요청·작업 완료가 화면 위에 카드로 떠서 놓치지 않습니다

## 설치

[**Releases 페이지**](https://github.com/Manggome/DdalgiTool/releases/latest)에서 내 컴퓨터에 맞는 파일을 받습니다.

- **맥 (Apple Silicon)** — `Ddalgi-<버전>-arm64.dmg`
  열어서 앱을 `응용 프로그램`으로 드래그. 처음 실행 때 막히면 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**
- **윈도우 (x64)** — `Ddalgi-<버전>-x64-setup.exe`
  SmartScreen 경고가 뜨면 **추가 정보 → 실행**

> 정식 인증서로 서명하지 않은 앱이라 처음 한 번만 위 과정이 필요합니다.

### 처음 설정

1. 사이드바에서 **Claude 개인 계정으로 로그인**
2. **작업 폴더** 선택 → **[🔗 연동 설정]**에서 구글·슬랙·트렐로 연결 (각 칸의 "연결 방법 보기" 참고)
3. 이 프로젝트에서 쓸 **드라이브 폴더·슬랙 채널·트렐로 보드·유니티 경로** 지정

### 업데이트

새 버전이 나오면 앱 안에 **업데이트 배너**가 뜹니다. 누르면 알아서 최신 버전으로 바뀝니다.

### 🎮 유니티 QA를 쓰려면

- 프로젝트 버전과 같은 **Unity 에디터** (Unity Hub로 설치)
- 유니티 프로젝트에 **MCP for Unity** 패키지
  (Package Manager → Add package from git URL → `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity`)
- **uv** — 맥: `curl -LsSf https://astral.sh/uv/install.sh | sh` · 윈도우(PowerShell): `irm https://astral.sh/uv/install.ps1 | iex`

준비가 됐는지는 새 대화 화면의 🎮 칩을 누르면 볼 수 있습니다.

## 자주 묻는 것

**업데이트 후 처음 켤 때 "키체인 접근 허용" 창이 떠요**
새 버전은 서명이 바뀌어서 macOS가 한 번 묻습니다. **"항상 허용"**을 누르면 연동이 그대로 유지됩니다.

**연동이 다 풀린 것처럼 보여요**
키체인 창에서 "거부"를 눌렀을 가능성이 큽니다. 딸기툴을 껐다 켜서 **"항상 허용"**을 누르면 다시 연결할 필요 없이 돌아옵니다.

**비용이 드나요?**
Claude는 각자의 개인 계정 사용량 안에서 씁니다. 구글·슬랙·트렐로 API는 무료 범위 안에서만 쓰도록 사용량 가드가 막아줍니다. 길어지는 작업이 걱정되면 입력창 아래 **비용 상한**을 켜두세요.

**작업이 오래 걸려요**
점검·QA·진단처럼 큰 일은 몇 분 걸릴 수 있습니다. 다른 앱을 봐도 끝나면 카드와 알림음으로 알려드려요. 그리고… 오래 걸리면 뭔가 나타날지도 🦖

## 개발자용

### 구조

- `src/main.mjs` — Electron 메인. 창·미리보기·권한 확인·사용량·인증·떠 있는 알림 카드
- `src/agent.mjs` — Claude Agent SDK 세션(WarmSession), 시스템 프롬프트, 대화별 연동 도구(MCP)
- `src/connectors/` — 구글·슬랙·트렐로 REST 클라이언트
- `src/renderer/` — 채팅 UI (시작 버튼·탭·찾기·작업 현황·서브 에이전트 카드·HTML 패널)
- `src/skills/` — 기획 업무 스킬. **SKILL.md 맨 위 정보(이름·아이콘·분류·예시·필요 연동·추천 노력)가 유일한 등록 정보** —
  폴더 하나 + SKILL.md 하나를 만들면 메뉴·시작 버튼·라우터·안내문에 자동으로 들어갑니다 (`src/skills.mjs`)
- `src/knowledge/도구지침.md` — 모든 스킬 공통 규칙 (첫 턴에 1회 로딩)
- `src/unity.mjs` — 유니티 QA: 에디터 찾기·열기, MCP for Unity 서버 설정, 안전 범위 판정(PreToolUse 훅)
- `src/designmap.mjs` — 설계 지도: 카탈로그·매핑 뼈대, 저장 정리, 그래프 보기(HTML) 생성
- `src/router.mjs` — 질문 분류(Haiku 5.5 + 구조화 출력) — 어떤 자료·스킬이 필요한지 힌트
- `docs/project.yaml.example` — 프로젝트 연결 설정(`.ddalgi/project.yaml`) 형식

> 토큰 절약: 로컬 인덱스 카탈로그 + 설계 지도 + 질문 분류로, 매번 전부 훑지 않고 **필요한 자료만** 읽습니다.

### 실행·빌드

```bash
npm start          # 개발 실행
npm run dist:mac   # dmg (arm64) → dist-app/Ddalgi-<버전>-arm64.dmg
npm run dist:win   # exe (x64)  → dist-app/Ddalgi-<버전>-x64-setup.exe
```

배포는 `./build/release.sh` 한 번으로 빌드 → 태그 → GitHub Release 업로드까지 진행됩니다.

- 설정 파일: `~/.ddalgi-tool/config.json`
- 시작 로그: `~/.ddalgi-tool/startup.log`

### 기반

Claude Agent SDK를 내장한 Electron 앱입니다. PrototypeBuilder 0.10.0 코드베이스를 포크해 만들었습니다.
