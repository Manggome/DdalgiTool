# 딸각기획 (딸기툴 🍓)

> **대화 한 줄로 게임 기획 잡무를 끝내는 도구.**
> 기획서·데이터 시트·슬랙·트렐로·유니티 코드를 하나로 연결해,
> 흩어진 자료를 일일이 찾아다니지 않고 **말로 물어보고 시키면** 됩니다.

딸기툴은 채팅 앱처럼 생겼습니다.
왼쪽에 대화창이 있고, 거기에 평소 말하듯 적으면 됩니다.

> "이번 기획서 요약해줘"
> "이 시트에서 밸런스 이상한 데 없나 봐줘"
> "○○ 채널에서 어제 정해진 거 뭐야?"

뒤에서는 Claude(개인 계정으로 로그인)가
연결된 구글 문서·시트·슬랙·트렐로·유니티 프로젝트를 직접 읽어 답합니다.

---

## 이런 게 번거로우셨다면

- 기획서가 문서 여기저기, 시트 여기저기 흩어져 있어 **매번 찾아 헤맨다**
- 시트 수식이 복잡해서 **어디서 숫자가 틀어졌는지** 눈으로 못 잡는다
- 슬랙에서 정해진 결정이 **스크롤 위로 사라져** 다시 못 찾는다
- 기획서에 달린 **댓글·수정 요청**을 하나하나 열어보기 귀찮다
- QA 항목을 **매번 처음부터** 손으로 정리한다

딸기툴은 이걸 "물어보면 답이 오는" 방식으로 바꿔줍니다.

---

## 무엇을 할 수 있나요

말로 시킬 수 있는 것들의 예시입니다. (실제로는 더 자유롭게 물어봐도 됩니다.)
새 대화 화면의 **"무엇을 할까요?" 버튼**에서 골라 시작할 수도 있고,
딸기툴이 "어떤 기획서요?"처럼 물을 때는 후보가 **버튼으로** 나와서 골라주기만 하면 됩니다.

**읽고 찾기**
- 기획서·시트·슬라이드 내용 요약하고 질문에 답하기
- 문서에 **탭이 여러 개여도 전부** 읽기
- 문서에 달린 **댓글·답글**을 모아서 정리 (미해결만 보기도 가능)
- 슬랙(등록된 채널)·트렐로 카드에서 필요한 내용 찾기

**검토하기**
- 데이터 시트에서 오류·이상치 찾기 (수식은 실제로 계산해서 검증)
- 기획서·데이터·코드·트렐로가 **서로 어긋난 곳**을 한 번에 점검해 보고서로 (지난 점검과 비교까지)
- 밸런스를 **시뮬레이션으로** 확인 (HTML 시뮬레이터도 만들어 줌)
- QA 체크리스트 만들기 → 원하면 **유니티에서 직접 플레이하며 테스트**하고 통과/실패 보고서까지

**정리하고 쓰기**
- 기획서·시트 수정 (단, **바꾸기 전에 항상 확인을 받음** — 아래 '안전장치' 참고)
- 양식을 학습해 **똑같은 형식으로** 새 기획서 초안 작성
- 결정 사항을 기록으로 남기기
- 시스템·재화·테이블·기획서·코드가 어떻게 이어지는지 **설계 지도**로 보기 (사이드바 🗺)

## 무엇과 연결되나요

| 연결 | 하는 일 |
|---|---|
| 📄 구글 워크스페이스 | 독스·시트·슬라이드 읽기/쓰기, 드라이브 파일 관리, **댓글 읽기** |
| 💬 슬랙 | **등록한 채널만** 대화 조회 · 메시지 전송(승인 후) |

| 🎮 유니티 | 코드·git 히스토리 읽기 · QA 때 에디터에서 **플레이 테스트** (프로젝트는 바꾸지 않음) |

## 안전장치 (중요)

기획 자료를 다루는 도구라, 실수로 뭔가 망가지지 않도록 선을 그어놨습니다.

- **바깥에 쓰는 일은 항상 먼저 확인** — 구글/슬랙/트렐로에 실제로 기록하기 전에
  "이렇게 바꿀게요, 할까요?" 카드가 떠서 **직접 허용을 눌러야** 실행됩니다
- **삭제 기능 없음** — 무언가를 지우지 않습니다.
  꼭 필요하면 이름 앞에 `[삭제용]` 이라고만 표시합니다
- **슬랙은 등록된 채널만** 읽습니다 (다른 채널은 볼 수 없음)
- **유니티 프로젝트는 바꾸지 않음** — 코드·씬·에셋은 읽기만 합니다.
  QA 플레이 테스트도 플레이·스크린샷·콘솔 확인만 하고, 수정·저장은 앱이 막습니다. 플레이 전에는 꼭 물어봅니다
- **로그인 정보는 맥/윈도우 키체인에** 암호화 저장 (채팅창에 붙여넣지 않음)
- **다른 앱을 보고 있어도** 승인 요청·작업 완료가 화면 위에 카드로 떠서 놓치지 않습니다

## 설치 (팀원용)

[**Releases 페이지**](https://github.com/Manggome/DdalgiTool/releases/latest)에서
내 컴퓨터에 맞는 파일을 받습니다.

- **맥 (Apple Silicon)** — `Ddalgi-<버전>-arm64.dmg`
  열어서 앱을 `응용 프로그램`으로 드래그.
  처음 실행 때 경고가 뜨면: **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**
- **윈도우 (x64)** — `Ddalgi-<버전>-x64-setup.exe`
  SmartScreen 경고가 뜨면: **추가 정보 → 실행**

> 사내 배포용이라 별도 서명이 없어 처음 한 번만 위 과정이 필요합니다.

### 처음 설정

1. 사이드바에서 **Claude 개인 계정으로 로그인**
2. **작업 폴더** 선택 → **[🔗 연동 설정]** 에서 구글·슬랙·트렐로 연결
   (각 항목의 "연결 방법 보기" 참고)
3. 이 프로젝트에서 쓸 **드라이브 폴더·슬랙 채널·트렐로 보드·유니티 경로** 지정

### 업데이트

새 버전이 나오면 앱 안에 **업데이트 배너**가 뜹니다. 누르면 알아서 최신 버전으로 바뀝니다.

## 개발자용

### 구조

- `src/main.mjs` — Electron 메인. 창·미리보기·권한 확인·사용량·인증·플로팅 알림 카드
- `src/agent.mjs` — Claude Agent SDK 세션(WarmSession)과 시스템 프롬프트, 연동 도구(MCP)
- `src/connectors/` — 구글·슬랙·트렐로 REST 클라이언트
- `src/renderer/` — 채팅 UI (탭·찾기·내가 한 말·작업 현황·HTML 패널)
- `src/skills/` — 기획 업무 스킬. **SKILL.md 맨 위 정보(이름·아이콘·분류·예시·필요 연동·추천 노력)가 유일한 등록 정보** —
  폴더 하나 + SKILL.md 하나를 만들면 메뉴·시작 버튼·라우터·안내문에 자동으로 들어간다 (`src/skills.mjs`)
- `src/unity.mjs` — 유니티 QA: 에디터 찾기·열기, MCP for Unity 서버 설정, QA 안전 범위 판정(PreToolUse 훅)
- `src/designmap.mjs` — 설계 지도: 카탈로그·매핑 뼈대, 저장 정리, 그래프 보기(HTML) 생성
- `src/knowledge/도구지침.md` — 공통 규칙 (첫 턴에 1회 로딩)
- `docs/project.yaml.example` — 프로젝트 연결 설정(`.ddalgi/project.yaml`) 스키마

> 토큰 절약: 로컬 인덱스 카탈로그 + Haiku 소프트 라우터로,
> 매 질문마다 전체를 훑지 않고 **필요한 자료만** 골라 읽습니다.

### 실행·빌드

```bash
npm start          # 개발 실행
npm run dist:mac   # dmg (arm64) → dist-app/Ddalgi-<버전>-arm64.dmg
npm run dist:win   # exe (x64)  → dist-app/Ddalgi-<버전>-x64-setup.exe
```

배포는 `./build/release.sh` 한 번으로 빌드 → 태그 → GitHub Release 업로드까지 진행됩니다.

- 설정 파일: `~/.ddalgi-tool/config.json`
- 시작 로그: `~/.ddalgi-tool/startup.log`
