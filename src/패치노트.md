## 0.7.0 — 2026-08-31

**대규모 사용성 개선 (9건)**

- **QA 스킬 개편** — 결과물이 항상 **HTML 체크리스트**로 나옵니다: 유저 행동 시나리오 중심,
  기대 결과 강조, 체크·실패 메모 저장(진행률 표시), 기술 근거는 접이식. 검토 후 "슬랙에 올릴까요?"
  확인을 거쳐 등록 채널에 파일 업로드(슬랙 앱에 files:write 스코프 추가 필요)
- **스킬 상세 보기** — ⚡ 메뉴 각 스킬의 ℹ 버튼으로 무엇을 하는지 내장 지침을 바로 확인
- **수정·생성한 기획서/시트가 브라우저로 자동 열림** (같은 문서는 5분에 1번)
- **HTML 패널에 📂 버튼** — 결과물을 Finder/탐색기에서 바로 열기
- **맨 아래 따라가기 수정** — 바닥에 있을 때는 새 내용을 자동으로 따라갑니다
- **완료 알림이 항상 OS 시스템 알림으로** (창을 보고 있어도)
- **유니티 프로젝트 복수 연결** — 여러 프로젝트 추가/제거 (읽기·깃·카탈로그 모두 반영)
- **드라이브 폴더 복수 연결** — 기획서/시트 폴더를 여러 개 등록 (검색·인덱스 모두 반영)
- 슬랙 파일 업로드 도구(slack_upload_file) 추가

- **doc_insert_after** — 기준 문단 "뒤에" 삽입하면 그 문단의 서식(●○■ 목록·중첩·폰트·색)을

- **소프트 라우터** — 본 모델 호출 전에 Haiku 가 카탈로그를 보고 필요한 소스·스킬 힌트를 붙입니다.
  힌트일 뿐이라 부족하면 본 모델이 스스로 확장하고, 실패해도 턴을 막지 않습니다

  의사결정 ADR(archive 스킬)과 함께 "예전에 뭐 했지?" 를 재검색 없이 답하는 재료가 됩니다
- '사본'·테스트 시트는 카탈로그에서 파일명만 남겨 크기를 줄였습니다

## 0.3.0 — 2026-08-28

**독스·슬라이드 쓰기 + 파일 관리 + 웹 패널**

- **독스·슬라이드 쓰기** — 문구 치환(doc_replace/slides_replace), 독스 끝에 추가, 슬라이드 장 추가,
  새 독스·슬라이드·시트 생성(drive_create). 실계정 E2E 검증 완료
- **드라이브 파일 관리** — 사본(drive_copy) · 이름 변경(drive_rename) · 폴더 이동(drive_move).
  **삭제·보관 기능은 정책상 없음** — 삭제가 필요하면 이름 앞에 `[삭제용]` 을 붙여 표시만 하고 사람이 지웁니다
- **웹 페이지를 툴 안에서** — open_page 도구로 구글 시트·트렐로 등 웹 화면을 오른쪽 패널에 띄웁니다
  (안 열리는 페이지는 기본 브라우저로 폴백)
- **시트 수식 인지** — sheet_read(formulas=true)로 수식 원문 확인, 수식 컬럼은 같은 패턴으로 기록.
  룩업(VLOOKUP) 결과가 비어 있으면 localize 테이블 신규 키 추가를 제안하는 규칙 추가
- **깃 연결** — 유니티 프로젝트 경로에 읽기 권한이 열려 git log/blame 조회 가능 (읽기 전용 — 커밋·푸시 금지)
- **승인창 가시성 개선** — 줄바꿈 보존, 창 확대, 요약 글자 확대, 경고문 강조
- **연동 설정에 "연결 방법 보기"** — 구글/슬랙/트렐로 각각 접이식 단계 안내 내장
- drive_search 가 대괄호·긴 파일명 검색에서 결과를 못 찾던 버그 수정 (단어별 매칭)

## 0.2.0 — 2026-08-28

**연동 계층 (M2)**

- 사이드바에 **[🔗 연동 설정]** 이 생겼습니다 — 구글 워크스페이스(OAuth 로그인) · 슬랙(봇 토큰) ·
  트렐로(키+토큰)를 연결하고, 프로젝트별로 드라이브 폴더 · 슬랙 채널 · 트렐로 보드 · 유니티 경로를
  지정해 `.ddalgi/project.yaml` 로 저장합니다
- 토큰은 **OS 키체인(safeStorage)에 암호화 보관**되고 화면에 다시 표시되지 않습니다
- 에이전트에 **연동 도구 20종**이 생겼습니다
  - 구글 읽기: 드라이브 검색 · 독스 · **슬라이드(발표자 노트 포함)** · 시트(탭 목록/범위)
  - 구글 쓰기: 시트 기록 · **독스 치환/끝에 추가** · **슬라이드 치환/장 추가** · 새 독스·슬라이드·시트 생성
  - 슬랙: 채널·히스토리·스레드 읽기, 발송 / 트렐로: 보드·카드·리스트 읽기, 카드 생성·코멘트
- **쓰기 도구는 권한 모드와 무관하게 항상 승인 창**을 거칩니다 (시트 수정·슬랙 발송·트렐로 쓰기)
- 슬랙은 **project.yaml 에 등록한 채널만** 조회합니다 (프라이버시 원칙)
- **API 사용량 가드** — 모든 외부 호출이 미터링을 통과합니다: 일일 80% 경고 토스트,
  분당/일일 상한 하드 차단, 429 백오프 + 연속 429 시 자동 일시정지. 사용량 모달에서 현황 확인

## 0.1.0 — 2026-08-28

**첫 버전 — PrototypeBuilder 0.10.0 기반 포크**

- 이름·아이콘을 **딸각기획 🍓** 으로 바꿨습니다
- **새 작업** 버튼이 온보딩 화면 대신 **새 채팅방**을 엽니다
- 게임 프로토타입 온보딩(게임 구상·화면 방식·리소스 폴더)을 제거했습니다
- **HTML 패널이 온디맨드**가 됐습니다 — 평소에는 숨겨져 있다가,
  시뮬레이터·리포트 HTML 이 생기면 자동으로 열립니다. 채팅 상단 [🖥 HTML 패널] 버튼으로도 열고 닫습니다
- ⚡ 스킬이 기획 업무 6종으로 바뀌었습니다 —
  기획서 · 데이터 테이블 · 밸런스 검증 · 탐색·정합성 · QA 테스트 케이스 · 아카이빙
- 스킬 절차서(SKILL.md + references)가 앱에 내장되어, 필요할 때만 읽어 토큰을 아낍니다
- 유튜브 조사 도구(yt-dlp)를 제거했습니다

**유지된 것** — 내가 한 말 목록 · 대화 내 찾기(⌘F) · 테마 · 모델 선택 · 권한 모드 ·
컨텍스트/계정 사용량 · 작업 탭(이름 변경·고정·삭제·대기열·완료 알림) · 이미지 붙여넣기 ·
슬래시 명령 · 작업 현황 · Claude 개인 계정 로그인
