# 예외처리 검수 체크리스트

기획서의 시스템/콘텐츠 기술이 아래 상황을 정의하고 있는지 검사한다.
판정은 3단계: **명시됨**(근거 문단 인용) / **누락** / **모호**(문장은 있으나 해석이 갈림).

## 1. 경계값·범위
- [ ] 수치의 최소/최대값과 도달 시 동작 (레벨 상한, 스탯 캡, 인벤토리 최대 등)
- [ ] 0 또는 음수가 될 수 있는 값의 처리 (골드 0에서 차감, 데미지 0 등)
- [ ] 소수점 처리 규칙 (반올림/내림/올림, 표기 자릿수)
- [ ] 확률 합이 100%가 아닐 때 / 천장(pity) 유무

## 2. 자원·재화
- [ ] 재화 부족 시 동작 (구매 실패 메시지, 유도 팝업 등)
- [ ] 우편함·보상함 만료, 수령 시 인벤토리 가득 참
- [ ] 중복 지급·중복 수령 방지 규칙

## 3. 시간·상태
- [ ] 이벤트/버프 기간 경계 (시작·종료 시각의 포함 여부, 타임존)
- [ ] 진행 중 시스템이 종료/점검을 맞을 때 (전투 중 이벤트 종료 등)
- [ ] 쿨타임·지속시간 중첩 규칙 (갱신 vs 무시 vs 합산)
- [ ] 오프라인/재접속 시 상태 복원

## 4. 동시성·순서
- [ ] 같은 대상에 동시 행동 발생 시 우선순위 (동시 처치, 동시 구매)
- [ ] 선행 조건이 사라진 경우 (퀘스트 대상 몬스터 삭제, 재료 아이템 회수)
- [ ] 연출 스킵/중단 시 보상·상태 처리

## 5. 사용자 이탈·실패 경로
- [ ] 취소/뒤로가기 시 자원·진행도 처리
- [ ] 네트워크 끊김·앱 강제 종료 시 복구 (특히 결제·뽑기 진행 중)
- [ ] 실패 시 재시도 가능 여부와 패널티

## 6. 조합·상호작용
- [ ] 다른 시스템과의 상호작용 (버프 × 이벤트 배율 곱/합 순서)
- [ ] 신규 시스템이 기존 콘텐츠에 소급 적용되는지
- [ ] 예외 등급/특수 아이템(이벤트 한정 등)의 시스템 적용 여부

## 리포트 형식

```
# 예외처리 검수: <문서명>

## 요약
명시 N건 / 누락 N건 / 모호 N건

## 누락
1. <항목> — 발생 시나리오: <구체 상황>
   제안 문안: "<기획서에 넣을 수 있는 문장>"

## 모호
1. <항목> — 현재 문구: "<인용>"
   해석 A / 해석 B — 확인 필요: <질문>

## 명시 확인됨 (근거)
- <항목>: "<인용>" (섹션명)
```

- 게임 장르·시스템 특성상 해당 없는 항목은 조용히 건너뛴다. 억지로 42개 항목을 다 채우지 않는다.
- 제안 문안은 해당 기획서의 기존 문체·용어를 따른다.
