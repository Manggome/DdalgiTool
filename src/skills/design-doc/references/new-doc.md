# 새 기획서 작성 가이드 (양식 학습)

## 1. 참조 문서 선정
- 사용자가 양식/참고 문서를 지정했으면 그것만 사용한다.
- 지정하지 않았으면: 인덱스 카탈로그에서 같은 카테고리(시스템/콘텐츠/이벤트 등)의 최신 기획서 2~3개를 후보로 제시하고 사용자에게 고르게 한다.
- 후보 문서 통독은 서브에이전트로 격리한다. 서브에이전트 지시: "이 문서들의 (1) 섹션 구조(제목 계층) (2) 각 섹션의 역할 한 줄 요약 (3) 반복되는 표/포맷 패턴 (4) 문체 특징(존댓말 여부, 용어 표기)을 추출하라."

## 2. 구조 확정
- 추출된 구조를 목차 형태로 사용자에게 보여주고, 새 기획서에 필요한 섹션 가감을 확인받는다.
- 이 단계에서 내용 관련 핵심 질문(대상 시스템의 목적, 범위, 연관 시스템)을 한 번에 모아 묻는다. 초안 작성 중에 찔끔찔끔 되묻지 않는다.

## 3. 초안 작성
- 학습한 구조·문체·표 포맷을 따른다.
- 수치가 필요한 곳에 임의 수치를 넣지 않는다. 미정 수치는 `[TBD]` 또는 `[밸런스 작업 필요]`로 표기하고, 밸런스 스킬로 산출 가능함을 안내한다.
- 기존 시스템을 참조하는 문장에는 근거 문서명을 각주처럼 표기한다: `(참고: <문서명> - <섹션>)`.
- 예외처리 섹션을 반드시 포함하고, `exception-review.md` 체크리스트 중 해당 항목을 미리 채운다.

## 4. 미리보기 → 승인 → 생성
- 초안 전문을 채팅에 미리보기로 출력한다 (마크다운).
- 생성 위치(드라이브 폴더)와 문서 제목을 함께 제시하고 승인을 받는다.
- 승인 후 구글 독스로 생성한다. 제목 규칙은 기존 문서들의 명명 패턴을 따른다 (예: `[시스템] 장비 강화 기획서 v1.0`).
- 생성 후 문서 링크를 보고하고, 작업 로그에 기록한다.

## 주의
- 참조 문서의 문장을 그대로 복붙하지 않는다. 구조와 포맷만 학습하고 내용은 새로 쓴다.
- 초안 분량이 매우 길면(약 10페이지 초과) 섹션 단위로 나눠 승인받는 것을 제안한다.
