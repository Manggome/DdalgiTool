# 📊 데이터 테이블 만들기·고치기 (data-table)

구글 시트 게임 데이터 테이블을 조회·수정·검수하고, 기획서를 근거로 새로 만든다.

## 언제 쓰나
값을 찾거나 고칠 때, 테이블 오류(중복 ID·빈 값·참조 깨짐)를 검사할 때, 새 테이블·행이 필요할 때.

## 꼭 지킬 규칙
1. **헤더부터**: 항상 탭 목록·헤더 행·행 수를 먼저 보고, 필요한 열·행만 읽는다.
   "전부 보여줘"도 행이 수백 개면 조건을 되묻는다.
2. **수식 열 보존**: 고치기 전 `sheet_read(formulas=true)` 로 수식 여부를 확인한다.
   수식 열은 값으로 덮지 않고, 새 행도 같은 수식 패턴(행 번호만 조정)으로 쓴다.
3. **룩업 빈 값 → 현지화 키 추가**: VLOOKUP 등으로 채워지는 name/desc 가 비거나 #N/A 면
   원본 localize 테이블에 키가 없는 것 — 룩업 셀을 덮지 말고 localize 행 추가를 제안한다.
4. **영향 먼저**: ID 변경·참조값 변경 전에는 🔍 찾기·영향 스킬의 영향도 확인을 제안한다.

## 절차
| 요청 | 흐름 |
|---|---|
| 읽고 답하기 | 시트·탭 특정 → 헤더 → 필요한 행만 → 출처(시트!범위)와 함께 답변 |
| 고치기 | 현재 값 조회 → 변경 전/후 표 → 승인 → 반영 → 다시 읽어 확인 |
| 오류 검수 | 스키마 파악 → 검수 스크립트 실행 → 결과 표 |
| 새로 만들기 | 기획서 근거 → 스키마 제안 → 승인 → 데이터 채움 → 미리보기 → 생성 |

## 결과물
