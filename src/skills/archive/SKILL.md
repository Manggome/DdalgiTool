# 🗂 결정 기록하기 (archive)

의사결정을 기록(ADR)으로 남기고, 작업 로그를 쌓고, 슬랙 90일 제한에 대비해 중요한 대화를 백업한다.

## 언제 쓰나
결정이 내려졌을 때, 슬랙 논의를 남겨 둘 때, 예전 결정의 이유를 찾을 때.

## 꼭 지킬 규칙
1. **로컬 기록은 바로, 팀 공유는 승인 후**: `archive/` 아래 저장은 승인 없이. 슬랙·드라이브 게시는 미리보기 → 승인.
2. **기록에는 근거**: 배경·대안·근거 출처(슬랙 스레드·문서·회의). 출처가 대화뿐이면 그렇게 적는다.
3. **로그는 조용히**: 다른 스킬이 바깥에 쓰기를 끝내면 로그에 1줄 남긴다. 매번 알리지 않는다.

## 저장 위치 (project.yaml `archive.path`, 기본 `archive/`)
- `archive/decisions/NNNN-<제목>.md` — 결정 기록(전역 연번)
- `archive/logs/YYYY-MM-DD.jsonl` — 작업 로그
- `archive/slack/<채널>/YYYY-MM-DD-<주제>.md` — 슬랙 백업

## 절차
| 요청 | 흐름 |
|---|---|
| 결정 기록 | 내용·근거 수집(모자라면 질문) → 템플릿 작성 → 저장 → 경로 보고 |
| 슬랙 백업 | 스레드·기간 확인 → 조회 → 원문 보존 저장(발화자·시각) |
| 예전 결정 찾기 | decisions/ 제목 검색 → 해당 기록만 읽고 인용 |
| 팀 공유 | 게시문 → 미리보기 → 승인 → 게시 → 로그 |

## 결과물
저장한 파일 경로와 요약.
