# QA HTML 체크리스트 형식

최종 산출물은 항상 이 형식의 **HTML 한 파일**로 작업 폴더에 저장한다.
파일명: `QA_<대상>_<YYMMDD>.html` (예: `QA_매니저스킬_260831.html`)

## 필수 요소

1. **머리말**: 대상(카드/기능) 이름, 생성일, 근거 문서 링크 목록, 진행률 바(`n/전체 · %`).
2. **케이스 행 — 유저 행동 중심**:
   - `<label><input type="checkbox"> [P1] TC-03 — <행동 시나리오>` 형태.
   - 시나리오는 "어디서 · 무엇을 한다 → 무엇이 보여야 한다"로, 비개발자가 그대로 따라할 수 있게.
   - 우선순위 P0(빨강)·P1(주황)·P2·P3 색 배지.
   - 각 케이스에 **메모 입력칸**(`<input class="memo">`) — 실패 시 증상 기록용.
3. **접이식 기술 근거**: 케이스마다 `<details><summary>근거·기술 정보</summary>…</details>` 로
   기획서 인용, 테이블 행(시트!범위), 코드 파일:라인을 숨긴다. 펼치기 전에는 안 보여야 한다.
4. **기획 공백 섹션**: 기대 결과를 정할 수 없는 항목은 체크리스트가 아니라 별도 "⚠ 기획 확인 필요" 목록으로.
5. **진행 저장**: 체크·메모를 `localStorage`(키: 파일명)에 저장해 새로고침해도 유지.
   모든 read/write 는 try/catch. "결과 요약 복사" 버튼(통과/실패/미실행 수 + 실패 케이스 목록 클립보드 복사).
6. **P0 먼저**: 케이스는 우선순위 순으로 정렬. 섹션(정상/경계/예외/상호작용)별 묶음.

## 스타일 지침

- 시스템 폰트, 다크·라이트 모두 무난한 중립 색. 한 파일 완결(외부 리소스 금지).
- 체크된 행은 흐리게 + 취소선. 진행률 바는 상단 고정(sticky).
- 화면 폭 좁아도(패널) 읽히게 한 컬럼 세로 배치.

## 흐름 (SKILL.md 6·7절과 세트)

파일 저장 → 패널 자동 표시 → "검토 후 슬랙에 올릴까요?" 묻고 대기 →
사용자 동의 시 `slack_upload_file(channel_id, "QA_….html", "QA 체크리스트 — <대상>")`.
