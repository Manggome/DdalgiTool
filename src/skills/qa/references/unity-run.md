# 유니티 플레이 테스트 (QA 4~5단계)

케이스를 만든 뒤 사용자가 "유니티에서 직접 테스트"를 고르면 이 절차를 따른다.
앱이 안전 범위를 강제한다: **플레이·스크린샷·콘솔·오브젝트 조회·테스트 실행만** 가능,
코드 실행·메뉴 실행·씬 불러오기는 **매번 승인**, 씬·스크립트·에셋 **수정/저장/삭제는 막힘**.

## 1. 준비
1. `unity_status` — 준비 상태 확인. `모자란것`이 있으면 그대로 안내하고 체크리스트만 만든다.
2. 꺼져 있으면 사용자에게 "유니티를 열까요? (1~3분)" 확인 → `unity_open`(승인 카드) → 1분 간격으로 `unity_status` 재확인 (최대 5분).
3. `unity_connect` — 이 대화에 유니티 도구(`mcp__unity__*`)를 붙인다.
   연결 실패면 "유니티 메뉴 Window > MCP for Unity 에서 브리지를 켜 주세요" 안내.
4. **사용자 확인**: "지금 유니티를 QA에 써도 될까요? (작업 중이면 플레이 모드로 바뀝니다)" — 턴을 끝내고 답을 기다린다.
   앱도 첫 플레이 때 승인 카드를 한 번 띄운다.

## 2. 테스트 전 상태 확인
- `read_console`(action get, types error/warning) — **플레이 전 이미 있는 오류**를 기록해 둔다 (테스트 탓이 아님을 구분).
- `manage_scene` get_active / get_hierarchy — 어느 씬인지. 필요한 씬이 다르면 사용자에게 알리고 `manage_scene` load(승인)는 꼭 필요할 때만.

## 3. 케이스 실행 (케이스마다 반복)
1. `manage_editor` play (처음 한 번) — 시작 직후 2~5초 기다린 뒤 진행.
2. **조작**: 유저 행동을 코드로 재현한다 — `execute_code`(승인 카드에 코드가 보임).
   - UI 버튼 누르기: 이름으로 GameObject 를 찾아 `Button.onClick.Invoke()`.
   - 게임 기능 부르기: 매니저 싱글톤의 공개 메서드 호출 (코드는 Read/Grep 으로 먼저 확인).
   - 값 확인: 재화·상태를 읽어 `return` 으로 돌려받는다.
   - **데이터를 지우거나 저장 파일을 바꾸는 코드는 쓰지 않는다** (PlayerPrefs.DeleteAll, File.Delete 등).
   - 한 번에 한 동작. 코드는 짧게, 무엇을 하는지 주석 한 줄.
3. **확인**: `manage_camera` screenshot (이미지로 돌려받음 — 앱이 Temp/DdalgiQA 에 저장)으로 화면을 보고,
   `read_console` 로 새 오류·예외를 본다. 기대 결과와 비교해 판정:
   - ✅ 통과 — 화면·값·콘솔 모두 기대대로
   - ❌ 실패 — 다름 (무엇이 어떻게 다른지 + 스크린샷 + 콘솔)
   - ⚠️ 확인 불가 — 재현 방법이 없거나 터치·제스처 등 코드로 흉내 낼 수 없음 (사람 확인 필요로 넘김)
4. 다음 케이스 전에 필요하면 상태를 되돌린다 (가능하면 플레이를 정지했다 다시 시작).
5. 끝나면 `manage_editor` stop — 플레이 중 바뀐 것은 정지하면 원래대로 돌아간다.

## 4. 테스트 코드가 있으면
`run_tests` (EditMode 먼저, PlayMode 는 init_timeout 120000) → `get_test_job` 으로 결과. 실패 테스트는 보고서에 따로.

## 5. 결과 보고서 `QA결과_<대상>_<YYMMDD>.html`
- 맨 위 한눈 요약: 통과 n / 실패 n / 확인 불가 n, 새로 생긴 콘솔 오류 n
- 케이스별 카드: 유저 행동 → 기대 → 실제 → 판정, 스크린샷(이미지 내장, 최대 960px), 관련 콘솔 로그(접기)
- 실패는 맨 위로, 심각도(P0~P3) 순
- "사람이 확인해야 할 것" 섹션 (확인 불가 케이스)
- 플레이 전부터 있던 오류는 따로 표시
- 체크리스트 파일(QA_…)이 있으면 같은 케이스 번호를 쓴다

## 하지 않는 것
- 씬·프리팹·스크립트·에셋 수정, 씬 저장, 패키지·설정 변경 (앱이 막는다)
- 사용자 확인 없이 유니티를 열거나 플레이하기
- 실제로 해 보지 않은 케이스를 "통과"로 적기
