# ⚖️ 밸런스 계산·시뮬레이션 (balance)

테이블 데이터와 실제 코드 수식으로 시뮬레이션 코드를 만들어 실행하고, 결과로 밸런스를 검증한다.

## 언제 쓰나
수치 계산·성장 곡선·전투 시간·재화 흐름 검증, 파라미터를 바꿔 보는 시뮬레이터가 필요할 때.

## 꼭 지킬 규칙
1. **수식은 코드가 진실**: 데미지 공식 등은 유니티 코드(C#) 구현을 먼저 확인한다.
   기획서와 다르면 그 차이를 반드시 보고한다.
2. **가정은 먼저 확인**: 데이터·코드에 없는 값(플레이 패턴 등)은 가정 목록을 먼저 보여 주고 확인받는다.
3. **시트는 직접 고치지 않는다**: 결과로 수치를 바꾸려면 📊 데이터 테이블 스킬의 수정 절차로 넘긴다.

## 절차
1. 수식 확보 — 설계 지도·매핑으로 관련 코드를 찾아 계산 로직을 읽는다 (없으면 기획서 수식)
2. 데이터 확보 — 필요한 열·행만 CSV 로
3. 스크립트 작성·실행 — 실제 데이터를 넣어 돌린다
4. 보고 — 결과 표 + 수식 출처 + 데이터 출처 + 가정 목록

## 결과물
결과 표와 요약. "바꿔 가며 보고 싶다"면 실제 데이터를 내장한 HTML 시뮬레이터(계산은 전부 JS).
