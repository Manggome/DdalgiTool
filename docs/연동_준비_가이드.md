# 딸기툴 연동 준비 가이드 🍓

딸기툴(딸각기획)이 구글 워크스페이스·슬랙·트렐로에 연결하려면 각 서비스에서
**앱 등록과 자격증명 발급**이 한 번 필요합니다. 팀 전체에 한 번만 하면 되는 작업입니다
(개인별 로그인은 나중에 딸기툴 연결 마법사에서 각자 진행).

| 서비스 | 소요 | 필요한 권한 | 산출물 |
|---|---|---|---|
| Google Workspace | 약 15분 | GCP 프로젝트 생성 권한 (+ 조직 내부용 동의 화면은 Workspace 조직 필요) | OAuth 클라이언트 JSON 1개 |
| Slack | 약 10분 | 워크스페이스에 앱 설치 승인 권한 | 봇 토큰 `xoxb-…` 1개 + 채널 ID 목록 |
| Trello | 약 5분 | 트렐로 계정 | API Key 1개 + 토큰 1개 |

## 공통 보안 수칙 (먼저 읽어주세요)

- 발급된 키·토큰은 **채팅·문서·스프레드시트에 붙여넣지 마세요.**
  딸기툴 M2의 연결 마법사에 직접 입력하면 OS 키체인(safeStorage)에 암호화 보관됩니다.
  그 전까지는 1Password 등 팀 비밀번호 관리자에 보관하세요.
- **Google: 결제 계정을 절대 연결하지 마세요.** 결제 미연결 프로젝트는 과금이 구조적으로
  불가능합니다 (쿼터 초과 시 429 에러만 발생). 2026년 중 쿼터 초과분 과금이 도입되어도
  결제 미연결이면 안전합니다.
- 토큰이 유출된 것 같으면 즉시 재발급(기존 토큰 revoke)하세요.

## 1. Google Workspace (약 15분)

> 결과물: OAuth 클라이언트 JSON 파일 (`client_secret_….json`)

### 1-1. GCP 프로젝트 만들기
1. https://console.cloud.google.com 접속 (회사 Workspace 계정으로)
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `ddalgi-tool` → 만들기
3. ⚠️ **결제 계정 연결을 묻는 화면이 나와도 건너뜁니다.** 이 가이드의 API는 결제 없이 동작합니다.

### 1-2. API 활성화 (4개)
`API 및 서비스 → 라이브러리`에서 아래 4개를 각각 검색해 **사용 설정**:
- Google Drive API
- Google Docs API
- Google Sheets API
- Google Slides API

### 1-3. OAuth 동의 화면 (내부용)
1. `API 및 서비스 → OAuth 동의 화면`
2. **User Type: 내부(Internal)** 선택 ← 사내 전용이므로 외부 심사가 필요 없습니다
   (내부 옵션이 안 보이면 개인 gmail 프로젝트입니다 — 회사 Workspace 조직 계정으로 다시)
3. 앱 이름 `딸기툴`, 지원 이메일 입력 → 저장
4. 범위(Scopes)는 지금 추가하지 않아도 됩니다 — 앱이 로그인 시 요청합니다

### 1-4. OAuth 클라이언트 ID 만들기
1. `API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID`
2. 애플리케이션 유형: **데스크톱 앱**, 이름 `ddalgi-desktop` → 만들기
3. **JSON 다운로드** 버튼으로 `client_secret_….json` 저장 → 이 파일이 산출물입니다

### 1-5. (선택·권장) 쿼터 상한 걸기
`API 및 서비스 → 할당량`에서 Sheets/Drive API의 분당 요청 상한을 무료 한도 아래로
낮춰 두면 이중 안전장치가 됩니다. 딸기툴 자체에도 사용량 가드(80% 경고 / 100% 차단)가 들어갑니다.

## 2. Slack (약 10분)

> 결과물: 봇 토큰 `xoxb-…` + 프로젝트 채널 ID 목록

### 2-1. 앱 만들기 (매니페스트 방식 — 권장)
1. https://api.slack.com/apps → **Create New App → From a manifest** → 워크스페이스 선택
2. YAML 탭에 아래를 통째로 붙여넣기 → Next → 권한 확인 → **Create**

```yaml
display_information:
  name: 딸기툴
  description: 딸각기획(기획자 툴)의 연동 봇 — 채널 검색·아카이빙용
  background_color: "#c43b54"
features:
  bot_user:
    display_name: 딸기툴
    always_online: false
oauth_config:
  scopes:
    bot:
      - channels:history
      - channels:read
      - groups:history
      - groups:read
      - chat:write
      - users:read
settings:
  org_deploy_enabled: false
  socket_mode_enabled: false
  token_rotation_enabled: false
```

매니페스트로 만들면 2-2는 이미 반영돼 있으니 2-3으로 건너뜁니다.
(수동으로 하려면 **Blank app**을 고르고 아래 2-2대로 스코프를 추가하세요. "AI agent" 템플릿은 불필요.)

### 2-2. 봇 권한(스코프) — Blank app으로 만든 경우만
`OAuth & Permissions → Scopes → Bot Token Scopes`에 추가:

| 스코프 | 용도 |
|---|---|
| `channels:history` | 공개 채널 메시지 읽기 (탐색·아카이빙) |
| `channels:read` | 채널 목록 조회 |
| `groups:history` | 비공개 채널 메시지 읽기 (봇이 초대된 곳만) |
| `groups:read` | 비공개 채널 목록 |
| `chat:write` | 아카이브 게시 등 메시지 발송 (항상 승인 후에만) |
| `users:read` | 메시지 작성자 이름 표시 |

### 2-3. 설치와 토큰
1. `OAuth & Permissions → Install to Workspace` → 허용
2. **Bot User OAuth Token** (`xoxb-`로 시작) 복사 → 이것이 산출물입니다

### 2-4. 봇을 프로젝트 채널에 초대 + 채널 ID 수집
1. 딸기툴이 읽어야 할 각 채널에서 `/invite @딸기툴`
2. 채널 이름 클릭 → 설정 팝업 맨 아래 **채널 ID** (`C0…`) 복사
3. 채널 ID들은 나중에 프로젝트 설정(`.ddalgi/project.yaml`)에 들어갑니다 —
   **여기 등록된 채널만 조회**하므로 프라이버시가 지켜집니다

참고: 사내 커스텀 앱은 2025년 non-Marketplace API 제한(분당 1회)의 **적용 대상이 아니며**,
슬랙 API는 호출당 과금이 없습니다. 무료 요금제는 90일 이전 메시지를 못 읽으므로
중요 결정은 딸기툴 아카이빙으로 90일 안에 백업합니다.

## 3. Trello (약 5분)

> 결과물: API Key + 토큰

1. https://trello.com/power-ups/admin 접속 → **New** (새 Power-Up/통합 만들기)
   - 이름 `딸기툴`, 워크스페이스 선택, 이메일 등 입력 (Iframe URL은 비워도 됩니다)
2. 만든 항목의 **API Key** 탭 → **API Key 생성** → 키 복사
3. 같은 화면의 **Token** 링크(수동으로 토큰 생성)를 클릭 → 권한 허용 → 표시되는 토큰 복사
4. 딸기툴이 쓸 보드의 ID도 확보: 보드 URL `trello.com/b/XXXXXXXX/이름` 의 `XXXXXXXX` 부분

참고: 트렐로 API는 전 요금제 무료이며(호출당 과금 없음), 제한은 API Key당 10초에 300회입니다.

## 4. 최종 체크리스트

- [ ] Google: `client_secret_….json` 파일 확보 (결제 계정 미연결 확인!)

이 4가지가 준비되면 딸기툴 M2 연결 마법사 개발에 착수합니다 —
마법사에서 위 값들을 입력하면 OS 키체인에 저장되고, 프로젝트별 연결
(`.ddalgi/project.yaml`: 드라이브 폴더·슬랙 채널·트렐로 보드·유니티 경로)이 완성됩니다.

> 각 서비스의 관리 화면 메뉴 이름은 UI 업데이트로 조금씩 달라질 수 있습니다.
> 막히는 단계가 있으면 딸기툴 채팅에 그대로 물어보세요.
