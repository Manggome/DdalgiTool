딸각기획 — 처음 실행하는 방법
=====================================

모바일 세로형 타이쿤 게임의 HTML 프로토타입을 대화로 만드는 프로그램입니다.

1) 왼쪽 앱 아이콘을 오른쪽 Applications 폴더로 끌어다 놓습니다.

2) 처음 실행하면 "확인되지 않은 개발자" 또는 "손상되었기 때문에 열 수 없습니다"
   경고가 뜹니다. 이 앱은 Apple 개발자 인증서로 서명되지 않았기 때문이며,
   앱에 문제가 있는 것은 아닙니다. 아래 둘 중 하나로 실행하세요.

   방법 A — 시스템 설정에서 허용 (권장)
     · 앱을 한 번 실행해서 경고를 띄웁니다.
     · 시스템 설정 → 개인 정보 보호 및 보안 → 아래로 스크롤
     · "'딸각기획'이(가) 차단되었습니다" 항목의 [열기 허용] 클릭
     · 다시 앱을 실행하고 [열기] 선택

   방법 B — 터미널에서 격리 속성 제거
     터미널을 열고 아래 한 줄을 붙여넣고 실행합니다.

       xattr -dr com.apple.quarantine /Applications/Ddalgi.app

3) 앱을 열면 왼쪽 아래에서 Claude 계정으로 [로그인] 합니다.
   (Claude 구독 계정으로 로그인합니다. 앱에 API 키를 넣을 필요는 없습니다.)

4) 만들어질 게임이 저장될 작업 폴더를 선택합니다. 빈 폴더를 새로 만드는 편이 좋습니다.

5) 처음 설정 화면에서 세 가지를 알려 줍니다.
     · 만들고 싶은 게임 (한 줄이면 충분합니다)
     · 참고할 게임 이름 — 적으면 인터넷에서 먼저 조사한 뒤 반영합니다
     · 배경·캐릭터·UI 리소스 폴더 — 없으면 비워 두세요.
       도형으로 만들거나, 라이선스가 명확한 무료 에셋을 받아서 씁니다.

6) [시작하기] 를 누르면 조사와 함께 필요한 질문 몇 개를 물어봅니다.
   답하시면 초기 프로토타입을 만들어 오른쪽 미리보기에 띄웁니다.
   "알아서 해줘" 라고 하시면 추천안으로 진행합니다.

7) 이후에는 자유롭게 대화하며 고쳐 나갑니다.
   파일이 저장될 때마다 오른쪽 미리보기가 자동으로 새로고침됩니다.

참고
----
· Apple Silicon(M1 이상) 전용입니다. Intel Mac 에서는 실행되지 않습니다.
· 제작 규칙과 질문 체크리스트는 앱에 내장되어 있습니다.
  왼쪽 아래 "제작 지침 보기" 에서 확인할 수 있습니다.
· 앱은 선택한 작업 폴더 안에서 파일을 읽고 쓰며, 셸 명령을 실행합니다.
  신뢰하는 폴더를 지정하세요.
· 문제가 생기면 ~/.prototype-builder/startup.log 를 확인하세요.
