딸각기획 (Windows) — 설치와 첫 실행
==========================================

모바일 세로형 타이쿤 게임의 HTML 프로토타입을 대화로 만드는 프로그램입니다.

설치
----
1) Ddalgi-<버전>-x64-setup.exe 를 실행합니다.
   관리자 권한 없이 사용자 폴더에 설치되며, 설치 위치를 바꿀 수 있습니다.

2) "Windows의 PC 보호" 파란 창이 뜨면
   [추가 정보] → [실행] 을 누르세요.
   코드 서명 인증서가 없는 프로그램이라 나오는 경고이며, 프로그램 문제는 아닙니다.

3) 백신이 설치를 막으면 예외로 등록하세요.
   설치 파일 안에 300MB 대의 실행 파일(claude.exe)이 들어 있어
   일부 백신이 크기 때문에 검사에 오래 걸리거나 오탐할 수 있습니다.

첫 실행
-------
1) 왼쪽 아래에서 Claude 계정으로 [로그인] 합니다.
   (Claude 구독 계정으로 로그인합니다. API 키를 넣을 필요는 없습니다.)

2) 만들어질 게임이 저장될 작업 폴더를 선택합니다. 빈 폴더를 새로 만드는 편이 좋습니다.

3) 처음 설정 화면에서 세 가지를 알려 줍니다.
     - 만들고 싶은 게임 (자세할수록 좋습니다)
     - 참고할 게임 이름 (한국어/영어 아무거나)
     - 배경/캐릭터/UI/레퍼런스 리소스 폴더 (없으면 비워 두세요)

4) [시작하기] 를 누르면 조사와 함께 필요한 질문을 몇 개 물어봅니다.
   답하시면 초기 프로토타입을 만들어 오른쪽 미리보기에 띄웁니다.

5) 이후에는 자유롭게 대화하며 고쳐 나갑니다.
   파일이 저장될 때마다 오른쪽 미리보기가 자동으로 새로고침됩니다.

권장 사항
---------
· Git for Windows 를 설치해 두시면 좋습니다.
  프로그램이 파일을 다루면서 셸 명령을 쓰는데, Windows 기본 환경에는
  그 셸이 없을 수 있습니다. 명령 실행 관련 오류가 나면 설치해 보세요.
  https://git-scm.com/download/win

· Node.js 가 있으면 만든 결과물의 문법 검사와 단일 파일(에셋 내장) 만들기가
  더 잘 됩니다. 없어도 프로토타입 제작 자체는 동작합니다.

알아 둘 점
----------
· 64비트 Windows 10/11 용입니다.
· 프로그램은 선택한 작업 폴더 안에서 파일을 읽고 쓰며 명령을 실행합니다.
  신뢰하는 폴더를 지정하세요. (입력창 아래에서 권한 확인 모드를 바꿀 수 있습니다)
· 문제가 생기면 %USERPROFILE%\.prototype-builder\startup.log 를 확인하세요.
