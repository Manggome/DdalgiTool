# 아이콘 관리

- 원본: `build/icon-source.png` (사용자 제공 — 딸기+클릭 커서, AI 생성)
- 풀블리드 중간본: `build/icon-fullbleed.png` (1024×1024, 본체 밖 잡티 제거본, 라운드 사각형)
- **macOS 적용본**: `build/icon-mac.png` — `node build/make-mac-icon.mjs` 로 생성.
  모서리까지 빨강으로 채운 **정사각형** + 글리프 80% 중앙 배치
- **Windows 적용본**: `build/icon-fullbleed.png` 그대로 (마스킹 없음 → 라운드 사각이 예쁨)
- `build/icon.png` (라운드+여백 824 그리드): 구버전 Finder 커스텀 아이콘용 유산. 더는 빌드에 안 쓰임

## macOS 26 (Tahoe) 아이콘 규칙 — 실측으로 확인한 것

파인더/독은 아이콘 모양을 검사해서 처리 방식을 정한다:

| 아트 형태 | 결과 |
|---|---|
| 모서리까지 채운 **정사각형** | ✓ 시스템이 직접 규격 스쿼클로 잘라 줌 (우리 방식) |
| **정확한 Apple 스쿼클** 실루엣 (예: PrototypeBuilder) | ✓ 그대로 표시 |
| 신형 `Assets.car` (Icon Composer, 예: ChatGPT) | ✓ 리퀴드 글래스 |
| 자체 라운드 사각/여백 (구 딸기 아이콘) | ✗ **회색·흰 판에 가두고 20% 축소** (icon jail) |

- 0.7.4~0.7.5 는 Finder 커스텀 아이콘(NSWorkspace.setIcon)으로 판을 피했지만,
  실행 전(파인더에서 처음 볼 때·DMG 안)에는 적용이 안 돼 판에 갇혀 보였다
- 0.7.6부터 정사각 아트 방식이라 꼼수 불필요 — main.mjs `clearFinderIcon()` 이
  남아 있는 구버전 커스텀 아이콘을 1회 제거한다

## 절차 (새 원본으로 바꿀 때)

1. 1024 리사이즈 후, 행별 불투명 run 기준으로 본체 밖을 투명 처리 → `icon-fullbleed.png`
   (라운드 사각형을 강제로 씌우면 원본 가장자리와 어긋나 노치가 생긴다 — 형태 보존 방식 사용)
2. `node build/make-mac-icon.mjs` → `icon-mac.png` 재생성
   (배경색은 원본에서 자동 샘플, 글리프는 채도 기준 자동 추출)
3. dev Dock 은 main.mjs 의 `app.dock.setIcon(icon-mac.png)`, 패키지는 electron-builder 가
   icon-mac.png 를 icns 로 변환 — 별도 작업 없음
