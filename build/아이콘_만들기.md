# 아이콘 관리

- 원본: `build/icon-source.png` (사용자 제공 — 딸기+클릭 커서, AI 생성)
- 풀블리드 중간본: `build/icon-fullbleed.png` (1024×1024, 본체 밖 잡티 제거본 — 여백 거의 없음)
- 적용본: `build/icon.png` (1024×1024, **Apple 아이콘 그리드에 맞춘 여백 포함** — `node build/pad-icon.mjs` 가 fullbleed 에서 생성)

## 절차 (새 원본으로 바꿀 때)

1. 1024 리사이즈 후, 행별 불투명 run 기준으로 본체 밖을 투명 처리 → `icon-fullbleed.png`
   (라운드 사각형을 강제로 씌우면 원본 가장자리와 어긋나 노치가 생긴다 — 형태 보존 방식 사용)
2. `node build/pad-icon.mjs` — 본체(bbox)의 긴 변을 824px 로 맞춰 1024 캔버스 중앙에 배치
   - Apple 그리드: 1024 캔버스에서 아이콘 본체는 824(약 80%)만 차지. 여백 없이 꽉 채우면 Dock 에서 이웃 앱보다 크게 보인다
   - 기준 실측: ChatGPT 앱 아이콘 본체 = 80.7% × 81.0%

## Dock 반영 방식 (macOS 26 Tahoe)

- Tahoe 는 신형 규격이 아닌 아이콘을 **회색 박스에 가두고 축소**한다 (icon jail)
- 해제: main.mjs 의 `applyFinderIcon()` 이 첫 실행 시 자기 번들에 Finder 커스텀 아이콘을 지정
  (`NSWorkspace.setIcon`, osascript JXA) — 마커 `버전:실행경로` 가 config `finderIconApplied` 에 저장됨
- `app.dock.setIcon()` 비트맵 지정은 회색 박스를 되살리므로, 마커가 일치하면 건너뛴다
- 버전이 바뀌면 마커 불일치로 다음 실행 때 자동 재적용 → 아이콘 교체는 버전 업만으로 배포됨
