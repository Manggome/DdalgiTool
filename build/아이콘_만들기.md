# 아이콘 관리

- 원본: `build/icon-source.png` (사용자 제공 — 딸기+클릭 커서, AI 생성)
- 적용본: `build/icon.png` (1024×1024, 본체 밖 잡티 제거 후 **여백 ~1%로 확대** — 여백이 크면 macOS 26 Dock 이 회색 판을 깐다)
- 새 원본으로 바꿀 때: 1024 리사이즈 후, 행별 불투명 run 기준으로 본체 밖을 투명 처리
  (라운드 사각형을 강제로 씌우면 원본 가장자리와 어긋나 노치가 생긴다 — 형태 보존 방식 사용)
- dev 실행 Dock 아이콘은 main.mjs 의 app.dock.setIcon 이 이 파일을 읽는다 (앱 재시작 시 반영)
